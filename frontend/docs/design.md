# デザイン方針

参考デザインとして **Spotify** を採用する。
- ダークテーマ基調
- 下部固定ミニプレイヤー→タップで全画面プレイヤーに展開
- 大きなカバーアート＋グラデーション背景
- チャプターリストはプレイリスト的な見せ方（記事1本＝1トラック）
- 波形/プログレスバーのシークUI

ただしSpotifyと異なり「探す・選ぶ」体験（検索・ライブラリ）は不要。ホーム→即再生→チャプター一覧、というシンプルな導線に絞る。
