# オンボーディング（テーマ選択）
**対応ディレクトリ**: `/frontend/app/onboarding`

## 概要
自由入力ではなく、タグ選択式でテーマを選ぶ画面。

## 仕様
- プリセットのタグ（例：「AI」「京都」「ゲーム」など）から複数選択
- 選択できるテーマは2〜3個まで
- 選択したタグはバックエンドAPI経由で`users.tags`に保存（[保存](../pipeline/06-storage.md)参照）。フロントエンドから直接DBは触らない
- 保存したタグは記事収集のカテゴリマッチングに使われる（[収集・正規化](../pipeline/01-fetch.md)参照）

## スコープ外
- 個人診断による興味判定（タグ選択式で代替。[Requirements.md](../../Requirements.md)のスコープ外参照）
