# ホーム
**対応ディレクトリ**: `/frontend/app/home`

## 概要
今日の番組が準備完了していることを示し、1タップで再生を開始する画面。アプリのアハモーメント（検索していないのに欲しい情報が届く驚き）の起点。

## 仕様
- アプリを開く（1タップ）→ その場でその日のラジオがすぐ再生開始
- 冒頭のセリフに前日との差分を反映：「おはようございます。今日は〇〇について3件動きがあります」（[重要度判定](../pipeline/03-score.md)の差分検知結果を使用）
- ホーム画面アイコンをタップ→ワンタップで再生開始（1タップ起動）

## 実装上の注意点
- **自動再生制限**：ブラウザはユーザー操作なしの音声自動再生をブロックする。ホーム画面アイコンのタップ→即座に再生開始、という1タップ導線で実現すること（完全な自動再生は不可能な前提で設計する）

## 関連
- 再生する番組データはバックエンドAPI経由で取得する（元は[保存](../pipeline/06-storage.md)の`programs/{programId}`）
- 生成バッチは固定時刻（毎朝6:00想定、Cloud Scheduler経由）で実行される前提（[Requirements.md](../../Requirements.md)参照）
