# プレイヤー
**対応ディレクトリ**: `/frontend/app/player`

## 概要
チャプターリストと記事リンク展開、シークバーを備えた再生画面。

## 仕様
- チャプター単位のシークバー
- 気になった話は元記事リンクを開ける（`chapters.source_url`をバックエンドAPI経由で取得。[保存](../pipeline/06-storage.md)参照）
- チャプターリストはプレイリスト的な見せ方（記事1本＝1トラック）

## デザイン
Spotifyを参考にしたUI（ダークテーマ、下部固定ミニプレイヤー→全画面展開、波形/プログレスバーのシークUI）。詳細は[Design.md](../../Design.md)参照。

## 関連
- 各チャプターは[要約・台本化](../pipeline/04-script.md)で記事1本＝1チャプターとして区切られたもの
- 音声ファイルは[音声化](../pipeline/05-tts.md)で生成され、バックエンドAPI経由でURLを取得する
